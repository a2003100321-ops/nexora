# `legacy-picktv` 分支计划

`legacy-picktv` 当前只保留计划，不创建、不推送，也不上传任何旧二进制。

启用该分支前必须完成：

1. 核实 PickTV 快照与 FongMi/TV 的精确版本或提交关系；
2. 建立逐文件来源、许可证、修改和署名台账；
3. 排除 Keystore、密码、Token、Cookie、用户日志与真实配置；
4. 排除来源不明的 AAR、SO、JAR、APK 和其他二进制；
5. 明确该分支只用于审计对照，禁止与 `develop` 直接合并；
6. 在首次远程创建前再次向项目所有者展示将上传的完整文件列表并取得确认。

推荐长期结构：

```text
main       稳定、可发布基线
develop    日常集成与里程碑开发
legacy-picktv（计划）经来源复核后的只读审计对照
```
