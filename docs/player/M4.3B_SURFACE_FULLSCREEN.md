# M4.3b 真实播放器 Surface 与横竖屏体验

## 阶段目标

M4.3b 让 Nexora 手机版在已有 `PlayerController -> Runtime -> Media3Engine` 链路上真实显示 Media3 视频画面，并补齐基础横竖屏体验。

本阶段仍然不开发字幕、弹幕、倍速、清晰度、音轨、选集、手势、投屏、DRM、VLC 或自动换源。

## 已实现内容

### 真实视频 Surface

`player:media3` 新增 `Media3VideoSurface`：

- 内部使用官方 Media3 `PlayerView`；
- 通过 Compose `AndroidView` 挂载到播放器页面；
- 绑定的是 `Media3SessionPlayerOwner` 持有的 Media3 `Player`；
- UI/feature 层不接触 ExoPlayer 类型；
- `PlayerView` 自带控制器关闭，继续使用 Nexora 自己的播放控制栏。

边界保持为：

```text
Player UI
  ↓
PlayerController
  ↓
Runtime
  ↓
Media3Engine
  ↓
Media3 PlayerView / Player
```

### Surface attach/detach

`player:media3` 新增 `Media3SurfaceAttachmentController`：

- Surface attach 只记录绑定状态；
- Surface detach 只解绑 view 与 player；
- detach 不释放播放器实例，避免 Compose 重组或页面短暂销毁导致播放会话被误杀；
- 播放器释放仍由 `PlayerController.Close` / MediaSession 生命周期负责。

### 横竖屏体验

`feature:player` 新增 `PlayerFullscreenState` 与 `PlayerFullscreenReducer`，表达纯业务状态：

- 普通模式：Portrait；
- 全屏模式：Landscape；
- 返回键在全屏状态下优先退出全屏；
- 非全屏状态下返回才离开播放器。

`app-mobile` 新增 `MobilePlayerFullscreenHost`：

- 点击“全屏”请求横屏；
- 点击“退出全屏”或系统返回退出横屏；
- 全屏状态使用 `rememberSaveable` 保存，支持 Activity 重建；
- 退出播放器时恢复系统默认方向。

### 播放位置保持

`feature:player` 新增 `PlayerSessionResumePolicy`：

- 当前播放状态已经属于同一个 `PlaybackSessionRequest.sessionId` 时，不重新 `Open`；
- Activity 重建、Compose 重组、横竖屏切换不会重新开始播放；
- UI 从 `PlaybackState` 恢复当前 position。

## 测试覆盖

新增测试：

- `Media3SurfaceAttachmentControllerTest`
  - 验证 Surface attach/detach 幂等；
- `PlayerFullscreenReducerTest`
  - 验证进入横屏、退出横屏、返回优先退出全屏；
- `PlayerSessionResumePolicyTest`
  - 验证同 session 旋转后不重新开始播放；
  - 验证播放位置可从状态恢复。

保留 M4.1、M4.2、M4.3a 的 Runtime、Media3、Player UI 基础测试。

## 当前限制

- Surface 已真实绑定 Media3 `PlayerView`，但仍使用 M4.3a 的基础控制栏；
- 未实现沉浸式隐藏系统栏；
- 未实现手势、倍速、清晰度、字幕、弹幕、音轨、选集；
- 未实现播放器错误自动恢复或自动换源；
- 当前测试播放入口仍使用内置 HTTPS MP4 示例请求。
