# ADR-0006：限定第一阶段存储范围

- 状态：已接受
- 日期：2026-07-15

## 背景

第三方网盘的真实类型、授权流程和登录样本尚未取得。提前建立通用“网盘”实现会依赖猜测，
并可能引入凭据处理和安全风险。

## 决策

第一阶段只允许以下存储类型：

1. 手机本地文件；
2. SMB；
3. WebDAV；
4. NFS。

`storage:api` 将这四种类型作为封闭枚举，分别建立实现模块骨架。M0～M2 不实现协议登录、
扫描、缓存或业务页面。其他网盘必须在获得真实类型、服务条款和登录样本后逐个评估，不能
以来源不明的 SDK、AAR、SO 或凭据样本占位。

## 后果

- 当前存储模块只提供边界和描述符，不具备实际浏览或播放能力。
- 新增存储类型需要更新本 ADR 或新增替代 ADR、模块依赖策略、凭据模型和测试样本。
- 密码、Cookie、Token 和用户日志不得进入仓库或测试语料。
