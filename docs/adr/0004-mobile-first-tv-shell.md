# ADR-0004：手机空壳先行，TV 当前只保留可编译入口

- 状态：已接受
- 日期：2026-07-15

## 背景

当前阶段的验收重点是工程、模块、安全和自动化基础，不是完整业务页面。手机端需要一个
可以启动的空壳首页用于验证应用入口和 Design System；电视端需要持续参加编译和 Lint，
但暂不开发电视业务。

## 决策

- `app-mobile` 使用包名 `com.nexora.mobile`，只展示基础工程就绪页。
- `app-tv` 使用包名 `com.nexora.tv`，注册 `LEANBACK_LAUNCHER`，只展示静态空壳。
- 两个应用共用 `core:designsystem`，但不能互相依赖，也不通过 flavor 覆盖同名界面。
- 两个入口都保留基本语义标题，使用 Compose 默认系统字体和 `sp` 缩放。
- 每次 CI 同时构建两个 Debug APK，防止 TV 空壳失去可编译性。

## 后果

- 当前仓库没有首页内容流、搜索、详情、播放、遥控器业务导航或电视播放器界面。
- TV 业务开始前需要新的功能设计和验收，不应从 PickTV 复制旧 Activity、Adapter 或资源。
- 完整 TalkBack 专项验收不是首版阻断条件，但新增界面仍需保留基础语义和系统字体兼容。
