# 当前限制

以下限制适用于当前 M0～M2 基础版本：

- `app-mobile` 只有工程就绪页；`app-tv` 只有静态可编译空壳。
- 没有数据源导入、首页内容、搜索、详情、播放、收藏、记录或设置业务。
- `source` 只包含端口、安全策略和测试语料框架；尚未实现 PickTV 配置解析或兼容桥。
- 合成语料中的 JAR、JavaScript、Python 地址只是惰性字符串；不会下载或执行插件。
- `live`、`notice`、DRM 当前只有“保留但不执行”的策略和样本，尚无产品功能。
- `player:media3` 只是依赖边界骨架，没有播放器会话、缓存或界面。
- 本地文件、SMB、WebDAV、NFS 模块尚未实现协议连接、登录、扫描或浏览。
- 不迁移 PickTV 收藏、播放记录、设置、凭据或旧 Room 数据库。
- 首版只保留基础语义标签和系统字体缩放，尚未进行完整 TalkBack 专项验收。
- 编译基线固定为正式 API 36；为避免引入 API 37 预览平台，部分 AndroidX 版本有意固定在
  仍支持 API 36 的稳定版本。
- 当前没有发布签名、Keystore、正式发布构建或应用商店配置。
- GitHub 远程仓库尚未创建或 Push；工作流只有在用户确认清单并完成授权后才会远程运行。
- 当前环境未连接 Android 设备或模拟器时，只能验证编译、Manifest 启动入口和 APK 产物，
  不能替代后续实机交互验收。

发现限制变化时，应同步更新路线图和相关 ADR，不能只修改代码。
